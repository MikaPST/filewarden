# FileWarden

**Secure Document Management for WordPress**

> **Status: pre-alpha scaffold. Do not use for real or confidential documents.**

FileWarden is a planned free, open-source WordPress document-management plugin focused on secure storage, inherited access control and modern publishing interfaces.

## Planned features

- Private adaptive storage with fail-closed safety checks
- Nested folders, categories and tags
- Public, authenticated and role-based access policies with strict inheritance
- Document detail pages, protected PDF/image previews and downloads
- Optional document versioning, trash retention and audit logging
- Shortcodes, Gutenberg blocks and Elementor integration
- French and English localization

**None of the above features are implemented in this scaffold.**

## Proposed compatibility targets

WordPress 6.8+, PHP 8.2+, MySQL 8.0+ or MariaDB 10.11+. These are targets, not yet verified compatibility claims. Use HTTPS.
