Pre-alpha document-management foundation. Not ready for production.

== Description ==

FileWarden 0.1.6-dev implements private-storage checks, inherited permissions, PDF/image uploads, protected downloads and minimal administration. It also provides protected previews, Media Library import and an Elementor-compatible shortcode. Integration and hosting validation are still required. Versions, trash and native editor widgets remain future work.

== Installation ==

Use single-site preproduction WordPress. Managed storage requires Sodium and verified HTTPS access restrictions. See docs/setup.md for verification, backups and the optional outside-webroot configuration. Do not use confidential documents before deployment validation.
