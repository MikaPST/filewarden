# Correctif de préproduction — même nom et explication des accès

Le propriétaire signale un échec générique pour l’import d’un document déjà présent dans le dossier, depuis l’ordinateur comme depuis la médiathèque. Lecture du code : le contrôle du nom bloque avant la comparaison du contenu, puis le client remplace l’avertissement précis par une erreur générique. Correction du comportement d’import déjà autorisé : comparer les contenus lisibles avant de bloquer le nom ; si le contenu est identique, proposer et afficher un nom libre numéroté avant confirmation. La copie reste indépendante, l’original intact. Le serveur revérifie le nom sous verrou et impose une nouvelle confirmation si la suggestion a été prise entre-temps. Le nom proposé est lié à la preuve de comparaison. Extension conservée ; aucun écrasement ni remplacement de version. Même nom mais contenu différent : conflit de nom distinct et explicite, sans fausse annonce de contenu identique. Droits et formats inchangés.

Pendant le correctif, le propriétaire demande explicitement de rapprocher Comprendre l’accès de la maquette approuvée : une étape par règle, pictogramme fonctionnel existant, source à gauche, règle à droite, note explicative dessous, mise en évidence des conditions et ambre pour l’ancien emplacement. Même rendu dans la fiche et dans la modale de droits. La chaîne serveur reste la seule source de vérité ; tous les ancêtres sont conservés, sans nom d’ancienne origine inventé.
