# FileWarden 0.1.12-dev

Cette préversion regroupe les dix évolutions du cahier des charges validé, y compris les fonctionnalités du lot 0.1.11-dev qui n’avaient pas encore fait l’objet d’une release.

- Navigation dans les sous-dossiers autorisés, fil d’Ariane borné et recherche dans le dossier ouvert.
- Héritage dynamique des droits et maintien de l’intersection de toutes les restrictions.
- Collection **Documents à classer** réservée à la gestion, non publiable.
- Suppression des dossiers sans sous-dossiers, avec récupération des documents et conservation des restrictions.
- Trois présentations d’accès restreint : Compact, Carte centrée par défaut et Bandeau éditorial.
- Interface Publication harmonisée, aperçu et code court synchronisés, lisibilité mobile.
- Réglages regroupés et diagnostic de stockage visible.
- Journal d’audit avec vues Simplifiée/Technique et détails dépliables. Les acteurs sont identifiés par leur **login WordPress et leur ID** ; les nouvelles entrées mémorisent le login au moment de l’action.
- Filtres par type, période et login WordPress, réinitialisation et purge manuelle confirmée avec trace conservée.
- Téléchargement direct **CSV, TXT et JSONL** de l’ensemble des événements filtrés, avec date dans le nom du fichier et retour de traitement/échec. Les exports restent indépendants de la page et du mode d’affichage.

Les noms des documents et dossiers dans l’audit exigent les droits de lecture du contenu. Les capacités de lecture et de purge d’audit restent distinctes. La migration vers le schéma 5 conserve les journaux, documents, UUID et politiques existants. Les anciens événements sont rapprochés d’un compte WordPress actuel si possible ; aucun nom n’est inventé pour un compte disparu.

Les contrôles automatisés de la release couvrent PHP 8.2–8.4, WordPress 6.8 et la version courante, MySQL 8.0, les routes HTTP, les permissions, les migrations, les exports de plus de 1 000 événements et les parcours Chromium/Firefox. Le détail des preuves est conservé dans `SUIVI.md` et les exécutions GitHub Actions.

Télécharger **filewarden-0.1.12-dev.zip**, puis remplacer l’extension depuis l’administration WordPress sans la désinstaller. Le fichier `.sha256` permet de vérifier l’intégrité du ZIP. Les archives « Source code » ne sont pas le paquet d’installation prévu.

Cette version reste une préversion : la réception sur l’hébergement réel et les diagnostics de stockage restent nécessaires. Cette publication n’installe rien sur le site utilisateur.
